# Render Farm 0.2.0

Render Farm manages local Maya and Blender render queues on Windows and macOS.

## Downloads

| Package | System |
| --- | --- |
| `Render-Farm-0.2.0-Windows-x64-Setup.exe` | Windows x64 installer |
| `Render-Farm-0.2.0-Windows-x64-Portable.exe` | Windows x64 portable executable |
| `Render-Farm-0.2.0-macOS-arm64.zip` | Apple Silicon Mac |
| `Render-Farm-0.2.0-macOS-x64.zip` | Intel Mac |

Maya and Blender are installed separately. FFmpeg is optional for additional previews and review movies. Packages are unsigned; platform security controls may require approval before first launch. SHA256SUMS.txt contains checksums for all four packages.

## Product updates

- English interface, scene checks, logs, and documentation.
- Mac application-bundle discovery and stable settings storage across the product rename.
- Separate stdout and stderr parsing, one exit event per process, and orderly renderer shutdown.
- Dedicated preflight and preferences modules.
- Updated Electron runtime and build dependencies.

Existing RenderFarm queue records, settings, presets, and PINs remain in place. Render outputs stay in their selected folders.

See the [user guide](https://github.com/ryonghwon/render-farm/blob/main/docs/USAGE.md) and [configuration guide](https://github.com/ryonghwon/render-farm/blob/main/docs/CONFIGURATION.md) for operation and storage details.
