Maya와 Blender 씬을 한 렌더 목록에서 무인으로 렌더하는 첫 공개 버전입니다.

## 다운로드

- `RenderFarm-Setup-0.2.1.exe`: 설치형
- `RenderFarm-Portable-0.2.1.exe`: 설치 없이 바로 실행

처음 실행할 때 Windows "PC 보호" 창이 표시되면 **추가 정보 > 실행**을 누릅니다.

## 주요 기능

- Maya(.ma, .mb)와 Blender(.blend) 씬을 한 목록에서 순서대로 또는 동시에 렌더
- 씬 파일 직접 분석: 프레임 범위, 해상도, 카메라, 렌더 레이어, 참조 파일, 없는 텍스처
- 렌더 전 점검과 한 번에 수정
- 렌더 후 프레임 파일 검증, 빠진 프레임만 자동 재렌더
- 중지 후 이어서 렌더, 비정상 종료 시 지연 재시도
- Arnold 라이선스 반환 대기
- 씬 여는 시간과 프레임 시간을 분리한 예상 시간
- 렌더 중 절전 방지, 완료 알림, 끝나면 PC 끄기
- Blender Cycles GPU 자동 선택(OptiX, CUDA, HIP, oneAPI, Metal)
- PIN 설정 잠금과 기본값 프리셋

## 지원 환경

- Windows 10, 11 (x64)
- Maya: Render.exe가 포함된 Maya, Arnold 렌더 확인
- Blender: 4.5 이상, 4.5와 5.2 씬으로 확인

## 알려진 제한

- 영문 외 문자가 들어간 경로의 Maya 씬은 경고만 표시
- 코드 서명이 없어 첫 실행 시 Windows 경고 표시
