# Render Farm 0.1.0

The first public release of Render Farm, a local batch render manager for Maya and Blender on Windows and macOS.

## Downloads

| Package | System |
| --- | --- |
| `Render-Farm-0.1.0-Windows-x64-Setup.exe` | Windows x64 installer |
| `Render-Farm-0.1.0-Windows-x64-Portable.exe` | Windows x64 portable executable |
| `Render-Farm-0.1.0-macOS-arm64.zip` | Apple Silicon Mac |
| `Render-Farm-0.1.0-macOS-x64.zip` | Intel Mac |

Maya and Blender must be installed separately. FFmpeg is optional for additional previews and review movies. Packaged apps do not require Node.js, Docker, or a separate browser.

## Features

- Combined queue for Maya `.ma` / `.mb` and Blender `.blend` scenes.
- Sequential and parallel rendering with per-scene frame ranges, cameras, output, and device settings.
- Scene checks, frame tracking, missing-frame retries, and interrupted-render recovery.
- Application discovery, render logs, output presets, and PIN-protected settings.
- Completion notifications, sleep prevention, and optional completion actions.
- Product documentation and illustrated guides in English; original Korean app interface.

Rendered files are saved directly to the selected output folder. Queue records and settings remain in the application data directory.

Mac archives are ad-hoc signed and checked for integrity, but are not notarized by Apple. Windows packages are unsigned. Your operating system may require approval before first launch. `SHA256SUMS.txt` contains checksums for all four packages.

See the [user guide](https://github.com/ryonghwon/render-farm/blob/main/docs/USAGE.md) and [configuration guide](https://github.com/ryonghwon/render-farm/blob/main/docs/CONFIGURATION.md) for usage and storage details.
