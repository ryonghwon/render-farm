# Render Farm 0.1.0

Local batch rendering for Maya and Blender on Windows x64.

## Downloads

| File | Package |
| --- | --- |
| `RenderFarm-Setup-0.1.0.exe` | Windows installer |
| `RenderFarm-Portable-0.1.0.exe` | Portable Windows executable |

This release contains the Korean-language interface. Maya and Blender must be installed separately.

## Included features

- Combined queue for Maya `.ma` / `.mb` and Blender `.blend` scenes.
- Sequential and parallel rendering with scene checks and per-scene overrides.
- Frame tracking, missing-frame retries, and interrupted-render recovery.
- Arnold license waits and Blender Cycles device selection.
- Render logs, completion notifications, and optional power actions.
- Presets and PIN-protected settings.
