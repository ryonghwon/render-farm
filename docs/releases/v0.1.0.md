첫 공개 릴리스입니다.

## 다운로드

| 파일 | 설명 |
| --- | --- |
| `RenderFarm-Setup-0.1.0.exe` | 설치형 |
| `RenderFarm-Portable-0.1.0.exe` | 단일 실행 파일 |

코드 서명이 적용되지 않은 빌드입니다. 첫 실행 시 SmartScreen 경고에서 **추가 정보 > 실행**으로 진행합니다.

## 주요 기능

- Maya(.ma, .mb)와 Blender(.blend) 씬 통합 렌더 목록, 순차 및 병렬 렌더
- 씬 파일 정적 분석과 렌더 전 점검
- 프레임 파일 검증, 누락 프레임 자동 재렌더
- 중단 지점부터 이어서 렌더
- 비정상 종료 지연 재시도, Arnold 라이선스 반환 대기
- 남은 시간 계산
- 렌더 중 절전 방지, 완료 알림, 완료 후 시스템 종료
- Blender Cycles GPU 자동 선택
- PIN 기반 설정 잠금, 기본값 프리셋

## 요구 사항

- Windows 10, 11 (x64)
- Maya: `Render.exe` 포함 설치본, Arnold 검증 완료
- Blender: 4.5 이상, 4.5와 5.2 검증 완료

## 알려진 문제

- 영문 외 문자가 포함된 Maya 씬 경로는 경고만 표시
